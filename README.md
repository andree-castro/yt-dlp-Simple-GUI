# YT-DLP Simple GUI

A simple graphical interface for `yt-dlp` to download videos and audio easily.

---

## 🚀 Features

- Download video from URL
- Download audio (MP3)
- Simple and lightweight GUI
- No terminal usage required (if you use the .exe version)

---

## 📦 Requirements

You must have `yt-dlp.exe` in the same folder as the application.

Download it here:  
[https://github.com/yt-dlp/yt-dlp/releases](https://github.com/yt-dlp/yt-dlp#release-files)

(Optional) For better audio/video compatibility:
- ffmpeg (not required for basic usage)

---

## 📁 How to use

### If using source code:
1. Install Python
2. Place `yt-dlp.exe` in the same folder as `app.py`
3. Run:

```bash
python app.py
